# Qogir icon theme

Scrolex includes three icons from the Qogir icon theme:

- `image-crop-symbolic.svg` comes from the file with the same name.
- `zoom-fit-width-symbolic.svg` comes from `xapp-view-fit-width-symbolic.svg`.
- `zoom-fit-height-symbolic.svg` comes from `xapp-view-fit-height-symbolic.svg`.
